# 📊 vater-hud | Ultra-Customizable Next-Gen HUD System

> **vater-hud** is an advanced, fully modular HUD resource designed for FiveM servers. Offering unmatched personalization, it features over **20+ distinct design variants** for every HUD component—from health, armor, and stamina to vehicle speedometers, minimaps, and status indicators. Powered by a sleek interactive NUI menu, players can construct their ideal interface in real time.

---

## 🚀 Key Features

* **🎨 20+ Variations Per Component:** Switch between 20+ unique visual styles for every element (Health, Armor, Hunger, Thirst, Stamina, Stress, Voice, Speedometer, and Minimap).
* **🖥️ Dynamic Live Layout Editor:** Drag-and-drop UI editor allowing players to reposition, resize, rotate, and adjust opacity for any HUD element directly on screen.
* **🏎️ Advanced Vehicle Telematics:** Custom speedometers (Digital, Analog, Cyber, Minimalist, Sports) displaying RPM, gear, fuel level, seatbelt alerts, engine health, and turn signals.
* **🗺️ Modern Minimap Controls:** Seamlessly toggle between square, circular, minimalist, and hidden minimap modes with customizable border colors and radar styles.
* **⚡ Ultra-Optimized Engine:** Built with a React/Vue framework and optimized NUI bridges, keeping resource usage strictly at `0.00ms` – `0.01ms` even during heavy vehicular updates.
* **💾 Profile Presets & Cloud Sync:** Save, load, and export custom HUD layouts/presets so players can share configurations across servers or switch setups instantly.
* **🌐 Framework & Status Integration:** Native support for `qb-core`, `es_extended` (ESX), `ox_lib`, dynamic stress, oxygen, custom jobs, and voice systems (`pma-voice`, `saltychat`).

---

## 📦 Dependencies

Ensure the following resources are installed on your server prior to running this script:

* **Framework:** `qb-core`, `es_extended` (ESX), or Standalone
* **Voice System:** `pma-voice`, `saltychat`, or native FiveM voice
* **UI / Utility:** `ox_lib`
