# 🔫 vater-gun | World-First Custom Weapon Personalization & Skin System

> **vater-gun** is a groundbreaking, industry-first weapon customization resource developed for FiveM. It allows players to fully personalize their firearms with custom parts, attachments, and unlimited **custom 3D skins/camouflages**. Designed with high performance and modularity in mind, it redefines weapon immersion on roleplay servers.

---

## 🌟 World-First & Key Features

* **🥇 World-First Innovation:** The first-ever fully modular weapon customization and custom skin framework created for FiveM global servers.
* **🎨 Unlimited Custom Skins:** Seamlessly add, configure, and apply custom textures, patterns, and custom-made skins to any supported weapon.
* **🔧 Modular Parts Customization:** Modify weapon components including scopes, suppressors, extended magazines, grips, flashlights, and receivers in real time.
* **⚡ Ultra-Optimized:** Zero performance impact during gameplay, maintaining an idle consumption of `0.00ms` with efficient asset streaming.
* **💾 Persistent Metadata System:** Weapon skin data and custom modifications are saved directly into item metadata, persisting across drops, trades, and inventories.
* ** Modern Interactive NUI:** Sleek 3D weapon preview inspection menu with dynamic rotation, zoom, and real-time color/skin adjustments.

---

## 📦 Dependencies

Ensure the following resources are installed on your server prior to running this script:

* **Framework:** `qb-core` or `es_extended` (ESX)
* **Inventory:** `ox_inventory`, `qb-inventory`, or any metadata-compatible inventory system
* **Database:** `oxmysql` or `mysql-async`
* **UI / Utility:** `ox_lib`
