# ⚡ vater-hud | Ultra-Fast & Minimalist PvP HUD System

> **vater-hud** is a lightweight, high-performance HUD resource engineered specifically for competitive FiveM PvP and GunRP servers. Built to eliminate on-screen distraction and maximize frame rates, it delivers sharp, real-time combat telematics, ultra-crisp health/armor bars, and zero latency—giving competitive players the ultimate operational clarity during high-tempo firefights.

---

## 🚀 Key Features

* **⚡ Zero Latency & Maximum FPS:** Engineered for high-tickrate competitive environments, running strictly at `0.00ms` with zero client-side micro-stutters during heavy gunfights.
* **🎯 Minimalist PvP Layout:** Clean, clutter-free design focused on high-priority combat indicators: Health, Armor, Stamina, K/D Ratio, and Weapon Telematics.
* ** Modern Crosshair & Hitmarker Module:** Built-in customizable crosshairs and dynamic hitmarkers complete with crisp audio feedback for landed shots and headshots.
* **📊 Real-Time Kill Feed & Combat Telematics:** Live combat log overlay displaying recent eliminations, weapon types, and active killstreak counters.
* ** Sleek Speedometer & Minimap:** Compact, high-definition vehicle telemetry for fast-paced drive-by engagements and tactical maneuvering.
* **🎨 Color Palettes & UI Customization:** Easily swap color themes, adjust bar positions, or toggle specific HUD modules via a quick in-game settings menu.

---

## 📦 Dependencies

Ensure the following resources are installed on your server prior to running this script:

* **Framework:** `qb-core`, `es_extended` (ESX), or Standalone (PvP Clean Frameworks)
* **UI / Utility:** `ox_lib` (or native lightweight NUI alternative)
